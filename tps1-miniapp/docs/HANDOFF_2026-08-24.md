# BÀI TOÁN TỔNG QUAN (24/08/2026)
Cập nhật quy trình tạo đơn hàng hộ khách qua Miniapp và thiết lập bảng giá Hợp Đồng riêng cho nhóm khách CUSTOM.

## 1. Tính năng Admin Tạo Đơn Hộ Khách (Draft Order)
**Vấn đề:** Sale cần tạo trước đơn hàng cho khách. Khách chỉ việc vào Miniapp kiểm tra lại và bấm xác nhận để tránh sai sót.
**Giải quyết:**
- Mở API endpoint `/api/admin/orders/create` cho phép Admin tạo đơn hàng ở trạng thái `draft`.
- Giao diện Admin (`quanly/js/admin-order-create.js`) thêm nút **Tạo đơn hàng mới** giúp Sale duyệt giỏ hàng, chọn khách và đẩy lên Supabase (gọi RPC `customer_create_order` nhưng ép status = `draft`).
- Phía Zalo Miniapp (`/api/customer/order/confirm`), khi thấy đơn trạng thái `draft`, nó sẽ yêu cầu khách bấm **Xác nhận đặt hàng**, sau đó đổi status thành `pending`.

## 2. Tính năng Bảng Giá Hợp Đồng Riêng (CUSTOM)
**Vấn đề:** Khách lớn có hợp đồng giá riêng (chốt theo năm). Nếu món nào không có trong hợp đồng thì lấy giá mặc định.
**Giải quyết:**
- Bổ sung bảng Supabase `customer_contract_prices` lưu giá hợp đồng từng mã hàng cho từng User.
- Ở giao diện Admin (Tab Quản lý VIP), bổ sung nút Hợp đồng giúp Sale xem/thêm/xóa danh sách sản phẩm giá riêng cho tài khoản nhóm CUSTOM.
- Tại Zalo Miniapp, khi khách đăng nhập, State (`contractPricesState`) tự động gọi `/api/customer/contract-prices` để fetch bảng giá riêng. Từ đó, danh sách sản phẩm hiển thị sẽ ưu tiên đè giá hợp đồng lên trên, fallback về mặc định nếu không có.

## 3. Khắc phục sự cố Git Submodule (repo quanly)
**Vấn đề:** Thư mục `quanly` ban đầu được quản lý ở repo riêng `dlltraded-tps1/quanly.git` nhưng bị lồng (embed) vào repo chính `dlltraded/thucphamsomot.git`.
**Khắc phục:**
- Do nhầm lẫn, thư mục `.git` của `quanly` đã bị xóa.
- Đã clone/init lại và set đúng remote (`dlltraded-tps1/quanly.git`), tiến hành commit và push cập nhật lên repo riêng này. Vercel cho Admin đã tự động build lại bình thường.
